# Tiqui Quiz

Tiqui Quiz превращает простой Markdown-документ в короткий интерактивный курс. Родителю или педагогу не нужны редактор кода, сервер, npm или доступ к интернету.

## Быстрый старт

1. Скачайте `quiz.html` и откройте его двойным кликом.
2. Загрузите `.md` через кнопку выбора файла или перетащите документ на страницу.
3. Исправьте найденные ошибки и проверьте курс во встроенном предпросмотре.
4. Нажмите «Скачать квиз HTML» и передайте полученный файл ребёнку.

Готовый HTML автономен: содержание, оформление и логика находятся в одном файле. Прогресс хранится только в браузере ребёнка.

## Формат документа

Документ начинается с названия курса. `Иконка`, `Описание` и `ID` необязательны. Стабильный `ID` полезен: по нему готовый квиз отличает свой сохранённый прогресс от других курсов.

```md
# Великие географические открытия

Иконка: 🗺️
Описание: Один урок — несколько минут
ID: geography-discoveries
```

Темы обозначаются заголовком второго уровня:

```md
## Морской путь в Индию

Иконка: 🧭
```

Вопрос начинается с заголовка третьего уровня. Поддерживаются пять типов.

### Выбор

Ровно один вариант отмечается `[x]`. Комментарий варианта необязателен и показывается только после проверки.

```md
### Выбор

Зачем европейцы искали морской путь в Индию?

- [x] За пряностями и дорогими товарами
  Подсказка: Верно: пряности в Европе стоили очень дорого.
- [ ] Чтобы найти Северный полюс
  Подсказка: Экспедиции шли вдоль Африки на юг.

Объяснение: Сухопутная торговля с Азией стала сложной и дорогой.
```

### Правда или ложь

```md
### Правда или ложь

Колумб понял, что открыл новую часть света.

Ответ: ложь
Если правда: Колумб до конца жизни считал новые земли Азией.
Если ложь: Верно — он был уверен, что добрался до Индии.
Объяснение: Поэтому местных жителей европейцы назвали индейцами.
```

Допустимые значения ответа: `правда`, `ложь`, `true`, `false`, `да`, `нет`.

### Ввод

Несколько допустимых ответов разделяются вертикальной чертой `|`. Регистр букв и повторные пробелы при проверке не учитываются. Небольшая опечатка засчитывается, но квиз показывает правильное написание.

```md
### Ввод

В каком году Колумб доплыл до Америки?

Ответы: 1492
Подсказка: Вспомни конец XV века.
Объяснение: Землю увидели 12 октября 1492 года.
```

### Порядок

Пункты записываются сразу в правильном порядке.

```md
### Порядок

Расставь события по порядку:

1. Колумб просит у королей корабли
2. Корабли выходят из Испании
3. Экспедиция пересекает океан
4. Моряки видят землю

Объяснение: Экспедиция вышла из Испании в августе 1492 года.
```

### Пары

Левая и правая части разделяются символами `=>`.

```md
### Пары

Соедини путешественника и открытие:

- Колумб => Америка
- Васко да Гама => Морской путь в Индию
- Беллинсгаузен и Лазарев => Антарктида
```

## Общие правила

- Не вставляйте HTML или JavaScript: они будут показаны как обычный текст.
- У каждой темы должен быть хотя бы один вопрос.
- У вопроса должны быть формулировка и данные, необходимые его типу.
- `Подсказка` и `Объяснение` необязательны и появляются только после проверки.
- Порядок тем в документе сохраняется. Вопросы внутри темы перемешиваются при каждом прохождении.
- Ошибочный вопрос возвращается в конец очереди, чтобы ребёнок попробовал снова.
- В выборе должен быть ровно один правильный вариант; одинаковые варианты запрещены.
- В вопросе «Правда или ложь» поле `Ответ` указывается ровно один раз.
- Пустые и повторяющиеся варианты в `Ответы` для свободного ввода автоматически удаляются.
- Элементы порядка не должны повторяться; сами номера могут идти не по порядку, поскольку важен порядок строк.
- Каждая пара должна содержать ровно один `=>`; левые и правые части разных пар не должны повторяться.

## Работа с нейросетью

Можно передать нейросети этот файл и попросить: «Создай курс по приложенному материалу в формате Tiqui Quiz. Разбей материал на темы по 6–10 коротких вопросов, используй разные типы вопросов и добавь понятное объяснение к каждому сложному ответу».

## Разработка и тесты

Для использования конструктора Node.js не нужен. Он требуется только разработчикам для автоматических тестов.

Первоначальная настройка:

```bash
make install
```

Запуск всех проверок:

```bash
make test
```

Отдельные наборы:

```bash
make test-unit
make test-browser
make test-browser-ui
```

`make help` выводит полный список целей. Соответствующие npm-команды также остаются доступны напрямую.

Модульные тесты проверяют Markdown-парсер непосредственно из `quiz.html`. Браузерные тесты запускают Chromium, загружают файл курса, проходят все пять типов вопросов и открывают экспортированный автономный HTML. Тестовые браузеры хранятся локально в `.playwright-browsers` и не попадают в репозиторий.
